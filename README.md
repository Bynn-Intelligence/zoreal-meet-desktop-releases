# ZOREAL Meet for Mac and Windows

The desktop app for ZOREAL Meet, identity-verified meetings. This repository holds the releases
and nothing else.

## Download

| Computer | File |
|---|---|
| Mac, Apple silicon and Intel | [ZOREAL-Meet-mac.dmg](https://github.com/Bynn-Intelligence/zoreal-meet-desktop-releases/releases/latest/download/ZOREAL-Meet-mac.dmg) |
| Windows | [ZOREAL-Meet-Setup-x64.exe](https://github.com/Bynn-Intelligence/zoreal-meet-desktop-releases/releases/latest/download/ZOREAL-Meet-Setup-x64.exe) |
| Windows on ARM | [ZOREAL-Meet-Setup-arm64.exe](https://github.com/Bynn-Intelligence/zoreal-meet-desktop-releases/releases/latest/download/ZOREAL-Meet-Setup-arm64.exe) |

These links always point at the newest release. Each release also carries a Mac installer
package (`.pkg`) and a Windows MSI for deployment by an IT department, and the previous
versions stay listed under [Releases](https://github.com/Bynn-Intelligence/zoreal-meet-desktop-releases/releases).

## Verifying a download

Every Mac release is signed with our Developer ID (Bynn Intelligence, Inc.) and notarized by
Apple. Each release lists the SHA-256 of every file in `SHA256SUMS`.

```sh
shasum -a 256 ZOREAL-Meet-mac.dmg
```
